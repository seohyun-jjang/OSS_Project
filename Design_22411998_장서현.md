# 1. Introduction

## 1.1 Summary

This document describes the design of the Inbody-Based Diet Recommendation System.

The system is designed to provide personalized diet recommendations based on users' Inbody information and health goals. Users can register, log in, enter their body composition data, set health goals, receive diet recommendations, record daily meals, and review nutritional feedback. The system also provides administrative functions for managing users and diet-related data.

This document presents the class diagram, sequence diagrams, state machine diagram, implementation requirements, glossary, and references used in the design phase of the project.

---

## 1.2 Important Points of Design

The main objective of this system is to provide personalized diet recommendations according to each user's physical condition and health objectives.

Important design considerations include:

- User-friendly interface for easy access to system functions
- Personalized diet recommendation based on Inbody information
- Health goal management for weight loss, muscle gain, and health maintenance
- Daily meal recording and nutritional feedback
- Data management through administrator functions
- Object-oriented design using Java classes and UML diagrams
- Modular structure to improve maintainability and scalability

The design focuses on separating user management, Inbody data management, diet recommendation, meal recording, and feedback functions into independent components to improve system flexibility and future extensibility.
